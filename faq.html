Frequently Asked Questions

Everything you need to know about Julex.

Is Julex free to use?

▼

Yes, Julex is completely free and open-source. We believe in providing high-quality tools to everyone without hidden costs.

Which browsers are supported?

▼

Julex supports all Chromium-based browsers, including Google Chrome, Microsoft Edge, Brave, Opera, and Vivaldi.

How do I update the extension?

▼

If you installed via the ZIP method, you'll need to download the latest version from our website and reload the extension in chrome://extensions.

Does Julex collect any personal data?

▼

No. Julex is designed with privacy at its core. All data processed by the extension stays locally on your device.

Can I customize the keyboard shortcuts?

▼

Yes! You can change all shortcuts in the extension settings panel to better fit your personal workflow.

Will Julex slow down my browser?

▼

Absolutely not. Julex is built using modern Manifest V3 standards which are highly optimized for performance and low resource usage.

Is Julex open source?

▼

Yes, the source code is available on GitHub. We welcome contributions and transparency.

How do I report a bug?

▼

You can report bugs or request new features by opening an issue on our GitHub repository.

Does it work on mobile browsers?

▼

Julex is currently designed for desktop browsers. Support for mobile browsers that allow extensions (like Kiwi or Yandex) may work but is not officially supported.

How can I support the project?

▼

You can support us by starring the repository on GitHub, sharing Julex with your friends, or contributing to the code!
